# T-046 — Accessibility audit + fixes

**Area:** mobile
**Estimate:** 60 min
**Depends on:** all screens (T-027..T-038, T-041, T-042)
**Implements PRD:** §8 (WCAG AA)
**Brand bible:** §6 (glyph + position redundant signifiers)

## Goal

Audit every screen against WCAG AA, fix issues. Ensure VoiceOver / TalkBack users can complete the entire daily ritual without sighted assistance.

## What to build

This is a fix-up ticket, not a new-feature ticket. Run a checklist over every screen and remediate.

1. **Contrast:** verify text-on-background ratios ≥4.5:1 (normal) / 3:1 (large). Fix tokens or specific instances if not met.
2. **Touch targets:** all interactive elements ≥44×44pt.
3. **Labels:** every Pressable / button has `accessibilityLabel` and `accessibilityRole`.
4. **Screen reader order:** every screen has a logical reading order (use `accessibilityElementsHidden` and `importantForAccessibility` to sequence).
5. **Quad accessibility:** verify VoiceOver announces "Quad. Mental: complete. Financial: not logged. Spiritual: in progress. Physical: not logged." per T-023 acceptance.
6. **Pillar coloring:** verify glyph + position carry the same information as color (color-blind safety, brand bible §6).
7. **Dynamic type:** support 100% to 200% via `allowFontScaling` on Text. Layouts don't break at 200%.
8. **Voice capture:** has a typing alternative path on every pillar where voice exists. Speech-to-text doesn't gate access.
9. **Reduce motion:** when `AccessibilityInfo.isReduceMotionEnabled()` returns true, disable the close-day animation (just snap to closed state) and pillar arc fills (snap, don't animate).
10. **Alt text on the Quad image** in the home widget.

## Acceptance criteria

- [ ] Manual VoiceOver pass: complete onboarding + a daily ritual end-to-end without looking at the screen.
- [ ] Manual TalkBack pass: same.
- [ ] Contrast checker passes for every text/background combo in both dark and light modes.
- [ ] All buttons have `accessibilityLabel`.
- [ ] At 200% dynamic type, every screen still readable with no clipped text.
- [ ] Reduce motion: close-day animation snaps to final state; arc fills are instant.
- [ ] No information conveyed by color alone — pillar identity is glyph + position + label.
- [ ] Tests: snapshot a few screens with VoiceOver simulated; assert role + label on key elements.
- [ ] Document any known limitations in `docs/a11y.md`.

## Non-goals

- Voice control beyond what iOS/Android provide natively.
- Screen magnification customizations.
- Switch control specific layout adjustments (v1.5).

## Notes for the agent

- Use `expo-modules-core`'s `AccessibilityInfo` proxy.
- Test with real device, not just simulator — VoiceOver behavior varies.
- The Quad's accessibility label should NOT include color names ("blue Mental") — those convey color, not state.
- For dynamic type at 200%, verify Fraunces large display doesn't overflow horizontally; consider auto-shrink with `adjustsFontSizeToFit` for short headlines.
