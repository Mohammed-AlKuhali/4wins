# T-045 — i18n scaffolding (en + ar + es)

**Area:** mobile
**Estimate:** 60 min
**Depends on:** T-022
**Implements PRD:** §1 (Ahmad persona — Arabic), §8 (localization NFR)
**Brand bible:** §3 (locked copy, must i18n cleanly)

## Goal

Wire i18n with English as the default and Arabic + Spanish as the v1 additional locales. Translate the locked copy from brand bible §3 into both. Right-to-left support for Arabic.

## What to build

1. **i18n library:** use `i18next` + `react-i18next`. Locale detection via `expo-localization`.
2. **Locale files:** `i18n/en.json`, `i18n/ar.json`, `i18n/es.json` — contain all the locked copy from brand bible §3.
3. **RTL handling:** when locale starts with `ar`, set RTL via `I18nManager.allowRTL(true)` and `I18nManager.forceRTL(true)`. Restart prompt shown if needed.
4. **Translation:** every Fraunces locked-copy string in the codebase replaced with `t('key')`. Brand-voice integrity in target languages (translator briefs forthcoming, but we lock the keys now).
5. **Missing-key behavior:** in dev, missing keys throw. In prod, fall back to English.

## Files to create / modify

```
apps/mobile/i18n/
  index.ts                       # i18next setup
  en.json
  ar.json
  es.json

```

## Acceptance criteria

- [ ] `t('onboarding.welcome_title')` returns the correct string in current locale.
- [ ] Locale changes at runtime via `i18n.changeLanguage()` re-render all screens.
- [ ] Arabic flips layout to RTL (mirror SafeArea, headers, navigation gestures).
- [ ] Missing key in dev throws; in prod falls back to English.
- [ ] All locked Fraunces copy in screens is sourced via `t()` — assert via grep test that no Fraunces-rendered Text component contains a hardcoded locked-string.
- [ ] Spanish + Arabic translation files structurally complete (translation quality is iteration; structure must be 100%).
- [ ] Tests: locale switch, RTL behavior, key fallback.

## Non-goals

- Translating non-locked utility copy in v1 — focus on the brand-locked strings first.
- More than 3 locales (German, French, etc. — v1.5).
- Server-side i18n for push notifications (v1.5; v1 = English only).

## Notes for the agent

- Spanish + Arabic translations should be done by professional translators with the brand bible §3 in hand. For this ticket, ship the file structure with first-pass translations (use Claude to draft); flag for human review pre-launch.
- Keep keys hierarchical and stable — they appear in tickets, code, and translator handoffs.
- For RTL: most Tailwind-style spacing is symmetric, but check icons (back arrows etc.) — they need `transform: { scaleX: -1 }` in RTL.
- Default locale is English unless device locale matches one of the 3 supported.
