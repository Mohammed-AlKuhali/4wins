# Project: 4Wins backend — initial Replit setup

## What you're building

4Wins is a mobile app for a daily four-pillar discipline ritual (Physical, Mental, Spiritual, Financial). This task sets up the **backend** that the iOS + Android client (built separately in Expo) will talk to.

You are NOT building the mobile app in this task. You are setting up the Node.js + Hono + Postgres + Drizzle backend that runs on Replit Reserved Deployments.

## Stack — non-negotiable

- Runtime: **Node 22**, ESM (`"type": "module"`).
- Framework: **Hono** v4+. Not Express, not Fastify, not Koa.
- Database: **Postgres** (Replit Postgres in the Reserved tier). Not MySQL, not SQLite, not Mongo.
- ORM: **Drizzle** with the `postgres` driver (the npm package literally named `postgres`). Not Prisma. Not pg. Not Sequelize.
- Validation: **zod**.
- Testing: **vitest**.
- Dev runner: **tsx**.
- Env loader: **dotenv**.
- All TypeScript, strict mode, NodeNext modules.
- Imports use `.js` extensions in source (ESM convention).

If any of those is unavailable on Replit, ASK — do not silently substitute.

## Project conventions

- Server port: **8787**.
- All routes under **`/v1/...`**.
- Error envelope: `{ error: { code, message } }`.
- Every later ticket imports env from `src/lib/env.ts` — never `process.env` directly.
- The repo will grow into a backend that has auth, daily-ritual endpoints, AI tagging, voice transcription, streaks, cron jobs, and IAP. This first task only sets the foundation.
